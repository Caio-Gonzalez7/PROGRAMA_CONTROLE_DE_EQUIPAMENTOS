# Controle de Equipamentos

Projeto em Python para praticar o desenvolvimento de um sistema simples de controle e cadastro de equipamentos.

## Funcionalidades atuais

- Cadastro de equipamentos
- Cadastro de patrimônio e número de série
- Validação de campos obrigatórios
- Bloqueio de patrimônio e serial repetidos
- Listagem dos equipamentos cadastrados
- Pesquisa por patrimônio
- Remoção de equipamentos com confirmação
- Resumo da quantidade de equipamentos cadastrados

## Conceitos praticados

- Python
- Listas
- Condições
- Estruturas de repetição
- Validação de entrada
- Git e GitHub

## Como executar

Tenha o Python 3 instalado e execute:

```bash
python main.py
```
