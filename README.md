# Controle de Equipamentos

Aplicação de terminal desenvolvida em Python para praticar o cadastro e a consulta de equipamentos por patrimônio e número de série.

## Funcionalidades

- Cadastro de equipamentos
- Validação de campos obrigatórios
- Bloqueio de patrimônio e serial repetidos
- Listagem dos equipamentos cadastrados
- Pesquisa por patrimônio
- Verificação de duplicados
- Remoção com confirmação
- Resumo da quantidade por tipo

## Conceitos praticados

- Listas e dicionários
- Funções
- Condições e estruturas de repetição
- Validação de entrada
- Organização e reutilização de código
- Testes automatizados com `unittest`

## Como executar

Tenha o Python 3 instalado e execute:

```bash
python main.py
```

## Testes

O projeto usa apenas recursos da biblioteca padrão do Python. Para executar os testes:

```bash
python -m unittest -v
```
